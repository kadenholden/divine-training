# Divine's Training

A personal gym log for Training Programme 1, built to be added to a phone's Home Screen and used like an app.

- Open the site on your phone, then add it to your Home Screen (iPhone: Safari → Share → Add to Home Screen; Android: Chrome → ⋮ → Add to Home screen / Install app).
- Everything logged is stored only on that phone (browser storage). Nothing is sent anywhere; there are no accounts.
- History → "Save a backup" exports the log; "Restore from a backup" brings it back.

Files: `index.html` (the whole app), `sw.js` (offline support), `manifest.webmanifest` and icons (Home Screen app).
